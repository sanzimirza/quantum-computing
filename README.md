# Quantum Computing Implementations

A collection of foundational quantum algorithms and protocols implemented in Qiskit. 

## Contents
* [Bernstein-Vazirani](link-to-folder) - Query complexity reduction.
* [Deutsch-Jozsa](link-to-folder) - Deterministic vs. constant functions.
* [Grover's Algorithm](link-to-folder) - Unstructured search.
* [Grover (IBM)](link-to-folder) - Implementation on real IBM quantum hardware, including noise analysis.
* [Noise](link-to-folder) - Simulating realistic quantum noise.
* [Quantum Fourier Transform](link-to-folder) - The core of many quantum algorithms.
* [Shor's Algorithm](link-to-folder) - Integer factorization.
* [Bell State & Teleportation](link-to-folder) - Foundational entanglement protocols.

## Setup
Requires Python 3.8+ and Qiskit.
